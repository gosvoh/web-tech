# web-tech

Лабораторные работы по курсу «Веб-технологии 2023 — Проектирование и анализ
языков веб-решений». Репозиторий одновременно является исходником сайта на
Jekyll, публикуемого через GitHub Pages.

Особенность работ: все словари разметки — **на русском языке**. Собственные
XML-словари (`<таблица>`, `<студент>`, `<строка>`, `<эллипс>`) преобразуются
XSLT-стилями в стандартные MathML и SVG.

## Содержание

| Работа | Тема | Материалы |
|---|---|---|
| `lab0/` | Введение в DTD | `dtd.dtd`, `file.xml` |
| `lab1/` | Введение в XSL | `task1/` — MathML, `task2/` — SVG |

### lab0 — DTD

Описание схемы ведомости с оценками средствами DTD. `dtd.dtd` задаёт структуру
`таблица → студент+ → отметка+` с обязательными атрибутами `имя` и `дисциплина`;
`file.xml` — документ, объявляющий эту DTD через `<!DOCTYPE>`.

### lab1 — XSLT

**Задание 1 (`task1/`) — MathML.** `math.xml` описывает формулу
среднеквадратичного отклонения на русском словаре (`корень`, `дробь`,
`низверх`, `операнд`). `math.xsl` разворачивает её в MathML (`<msqrt>`,
`<mfrac>`, `<munderover>`, `<mi>`, `<mo>`) и подключает MathJax для рендеринга
в браузерах без нативной поддержки.

**Задание 2 (`task2/`) — SVG.** `graphics.xml` описывает три полупрозрачных
пересекающихся круга на словаре `графика` / `эллипс` (`заливка`, `ободок`,
`ширина-ободка`). `graphics.xsl` отображает их в `<svg>` / `<ellipse>`.

Оба XML-документа связаны со своими стилями через инструкцию
`<?xml-stylesheet type="text/xsl" href="..."?>` — преобразование выполняет сам
браузер, сборка не нужна.

## Просмотр

Достаточно открыть XML-файл в браузере — XSLT применится автоматически:

```
lab1/task1/math.xml
lab1/task2/graphics.xml
```

> Chrome блокирует XSLT для файлов, открытых по схеме `file://`
> (ограничение CORS). Открывайте через локальный сервер, например:
>
> ```bash
> python -m http.server 8000
> ```
>
> и переходите на <http://localhost:8000/lab1/task1/math.xml>.
> В Firefox `file://` работает без обходных путей.

## Сайт

Страницы собираются Jekyll из Markdown-файлов с front matter:

- `index.md` — главная; список разделов строится автоматически обходом
  `site.pages` (страница с `is_home: true` из списка исключается)
- `lab0/README.md`, `lab1/README.md` — страницы работ с `permalink`
- `_layouts/page.html` — единственный макет, минимальный HTML-каркас
- `_config.yml` — плагин `jekyll-relative-links` для относительных ссылок
  между файлами репозитория

Локальный запуск:

```bash
bundle exec jekyll serve
```
